## Краткое описание проекта

ShopProject — учебный сайт интернет-магазина, разработанный на HTML и CSS. Проект включает главную страницу с hero-блоком, блок преимуществ, карточки популярных товаров с бейджами («Новинка», «Скидка», «Хит»), aside-блок с информацией и модальное окно с формой заявки. Оформление построено на CSS-переменных, Flexbox, CSS Grid и базовом БЭМ-именовании классов. Навигация — единая, есть якорные ссылки.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.
- `sitemap.xml` — простая карта сайта;

## Используемые технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3** — внешний файл `css/style.css`; CSS-переменные в `:root`; Flexbox; CSS Grid; базовое БЭМ-именование; позиционирование (`relative`, `absolute`, `sticky`); `z-index`; состояния `:hover`, `:focus-visible`, `:disabled`.
- **JavaScript** — минимальная логика открытия/закрытия модального окна и валидации формы.
- **Git / GitHub / GitHub Pages.**

## Что реализовано

- **Flexbox** — для шапки, меню, карточек товаров, кнопок формы.
- **CSS Grid** — для сетки карточек товаров.
- **БЭМ-именование классов** — `site-header__inner`, `site-nav__link--active`, `product-card__title`, `product-card__badge--new`, `order-form__field` и др.
- **Позиционирование**:
  - `position: sticky` — для шапки;
  - `position: relative` — для карточки товара;
  - `position: absolute` — для бейджей;
  - `z-index` — для шапки.
- **CSS-переменные** в `:root` — цвета, отступы, скругления.
- **Состояния** `:hover`, `:focus-visible`, `:disabled`, а также `[aria-invalid="true"]`.
- **Модальное окно** на `<dialog>` с затемнением фона через `::backdrop`.
- **README.md** с описанием проекта и ссылками.
